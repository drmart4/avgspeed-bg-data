# Участъци за средна скорост в България

Данни за iPhone приложението „Средна скорост“: сертифицираните отсечки за контрол на средна скорост с координати на началото и края, дължина и ограничения.

Файлът, който приложението чете: [`sections.json`](sections.json)

```json
{ "version": "2026-11-16.1", "generated": "...", "source": "...", "sections": [ ... ] }
```

## Откъде са данните

- **Списък на участъците:** [BG TOLL – сертифицирани отсечки за средна скорост](https://www.bgtoll.bg/vaprosi-i-otgovori/sredna-skorost/wim) (път, начало и край с километър).
- **Координати и ограничения:** © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, лиценз ODbL – тол рамки, пътища, населени места и `maxspeed`.

BG TOLL не публикува координати и ограничения. Затова те са изчислени и може да са неточни. `verified: true` означава, че дължината по пътя в OpenStreetMap съвпада с официалната до ±10%. `speedLimit` е предпазлива стойност. Данните са помощни и не заместват пътните знаци.

## Автоматично обновяване

GitHub Actions ([`update.yml`](.github/workflows/update.yml)) всеки понеделник сверява списъка на BG TOLL и OpenStreetMap. Нова версия се публикува, само ако има промяна и данните минат проверките. Може да се пусне и ръчно: **Actions → Обновяване на участъците → Run workflow**.

Локално: `python3 tools/update.py`. Ръчните корекции на точки са в речника `OVR` в `tools/build6.py`.
